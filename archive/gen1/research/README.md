# Research laboratory

This directory is reserved for reproducible experiment inputs, scripts, raw
measurements, and reports governed by [the benchmark plan](../docs/BENCHMARK_PLAN.md)
and [provenance policy](../docs/PROVENANCE.md).

Research results are not protocol constants until an explicit decision record
promotes them. Simulation is not executable liquidity, local-validator execution
is not mainnet evidence, and no result authorizes financial or network action.
