# Fixture contract

Fixtures will be synthetic by default, canonical, reproducible, and accompanied
by a provenance/derivation manifest. Planned families are `kernel`, `partition`,
`accumulator`, `batch`, `solana`, and `cross-runtime`.

No fixture may contain wallet material, secrets, provider credentials, browser
state, unexplained real account data, or copied inputs without a compatible
license and exact provenance. Minimized adversarial failures become permanent
named fixtures rather than anonymous blobs.
