# Guides

Thin, hand-written entry points. Everything quantitative they mention lives in
the [generated reference](../reference/README.md), which is regenerated from
the protocol's own authorities and byte-verified — the guides link into it
rather than restating it.

- [Trader guide](trader.md) — what a claim is, how range protection works,
  what a refusal means, and the vocabulary this project refuses to inflate.
- [Operator guide](operator.md) — founding a market, capabilities and
  funding compartments, choosing resolution windows, and the failure walk.
- [Reader guide](reader.md) — what the demo will be when it lands, what it
  will not claim, and how to run the whole thing locally today.

Evidence level, once for all three: dClutch is not deployed to any cluster
and nothing is released. The guides describe the protocol as implemented and
executed locally.
