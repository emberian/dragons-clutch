`SeriesCurrentAcquisitionInputV5`, current release input, portable accepted
intent, payer, chain genesis and frozen lookup observation. It invokes the
existing lifecycle, release emitter, selector, acquisition and Hot inspector,
then emits the durable operation source consumed by the paired local/devnet
CLI. No additional alias, privilege, schedule or economic rule is introduced.

Prepare/Consume/Expire retain the native occurrence proof and exact Ticket
record/replay role. Retire retains its terminal Ticket route. Expire/Retire/Close
retain the acquired RentCredit as applicable. Consume serializes its native
Shadow request with the native encoder and carries the checked deployment
digest plus observed certificate/artifact/program/ProgramData/caller addresses.
The accepted portable intent is rechecked before a source is written.
All actions share one common fixed-address projection.

is already connected to Found/Prepare. Connecting subsequent-action authoring
to this new seam, browser transport, and the selected-runtime complete lifecycle
are outstanding; the existence of the function is not execution evidence.
