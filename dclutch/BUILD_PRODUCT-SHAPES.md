## 3. Provisional rulings (ember rules by reversal)

1. **Where the reference is named.** `SourceSpecV1.adapter_config_id` names the
   `ParentReferenceV1` record (the per-market adapter slot, as `PythAdapterConfigV1`);
   the derived family's `ProviderReleaseV1` is one constant release whose
   `decoding_rules_id` is `DERIVED_DECODING_RULES_ID_V1`. The design note §2.1
   said `decoding_rules_id`; that slot is a cross-market layout table. Corrected
   in the ABI module's header, not in the dated note.
2. **The access profile is a fifth variant**, `DerivedFromParents = 5`, Lean-owned.
3. **The Found frame's parent tail is appended to the canonical frame only**
   (widths 37 / 39 / 49, never 51): a child's basis is categorical and refunding,
   so a price-gate pair and a parent tail never coexist.
4. **`ordinary_count` is PROVED at founding**, against each parent's own
   `ResultDomainV2` reached through its Product record (five accounts per parent)
   rather than trusted from the founder — an understated count would refund
   holders on an ordinary parent outcome, an overstated one would mint against dead
   cells. The price is twelve accounts of tail.
5. **`WindowBeforeParents` is a compiler conjunct, not a Core one.** Neither the
   parents' windows nor the child's own are in the Found frame; the settle route
   binds `reference.settle_by` to the child's `WindowSpecV1.end_unix_seconds`
   (`DerivedReference`), and a child that reaches `settle_by` with a parent live
   walks to its failure coordinate and refunds — the founder's mis-sizing, which
   the bond prices (ruling 7). Reversal: four more tail accounts per parent.
6. **`AttestedUnobservable` is NOT built this generation** (design §4.3, owed
   ruling 2): the first child walks the deadline on a parent's failure certificate.
   Reason: it is one conjunct on `SourceResolution.lean`'s `exhaust` and the Source
   machine's owner in this wave is the failure-arm family; a second author of the
   exhaust conjunct in the same wave is the enmeshing hazard the preamble names.
   Named as debt in §4.
7. **The child founder's bond applies, at the size rule** (design §4.3, owed
   ruling 3; decision 0033). The rule's terms are computable for a child
   (`S = rent(312)`, `F` the opener's advance, `Λ` one rung's bounty for the
   deadline walk), and the purpose survives: the founder chose the parents and
   the margin, which IS the child's oracle choice.
8. **Native venues in the relay.** A row whose state is owned by a program the
   validator implements (Feature program, sysvar owner) carries no
   `Program`/`ProgramData` positions; the Loopscale defense degenerates to the
   pinned entry's owner byte plus the pinned address, which no transaction on the
   observed cluster can move.
9. **The dormant-feature sentinel.** A `None` feature yields `2^64 − 1`; the
   market's window start is the founder's calendar for slot `S`. Nine bytes cannot
   say when they were observed not to be activated; the attested mainnet
   `unix_timestamp` inside `[start, end]` is what makes the observation about a
   period after `S`. The residual — the founder's unix estimate of `S` — is
   recorded here; the parent B metric is, fittingly, what would move it.
10. **The tenth item stays OPEN and is ember's**: which feature, which slot `S`,
    slot time or SOL/USD, and the disclosure line. Everything below is built with
    those as founding INPUTS (`--feature-gate`, `--activation-slot`, `--metric`,
    `--thresholds`, `--window`), so ember's choice is three flags and a calendar.

11. **(CLOSEOUT, provisional.)** The `Native` arm reuses
    `Error::ObservedOwnerMismatch` for a wrong epoch-schedule sysvar address
    (`decode.rs:935-984`) rather than adding a variant. Defensible — it is an
    owner-class refusal in spirit — but it means a mis-seated sysvar and a
    mis-owned account are indistinguishable in the log. Reversal: one variant.
