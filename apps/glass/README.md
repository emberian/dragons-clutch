# Glass static client scaffold

No client code exists yet. Glass is planned as a reproducible, static, secret-free
projection and transaction-construction tool for user-selected RPC and wallet
connections. It owns no protocol truth, index, matcher, source, or signing
authority.

The first client artifact remains offline/unsigned until its schema, manifest,
CSP, supply-chain, accessibility, malicious-client, and Gate L0 requirements are
closed. GitHub Pages is a mirror; an immutable content digest and release manifest
are the identity.
